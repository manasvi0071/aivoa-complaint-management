**# AIVOA Complaint Management System**



**AI-powered customer complaint management system for pharmaceutical manufacturing (API/FDF), built for AIVOA Round 1 assignment.**



**## Stack**

**- Frontend: React + Redux Toolkit**

**- Backend: FastAPI + LangGraph**

**- LLM: Groq (openai/gpt-oss-20b, openai/gpt-oss-120b) — migrated from gemma2-9b-it after Groq decommissioned it**

**- Database: SQLite (SQLAlchemy)**



**## Features**

**- Document upload (PDF/text) with AI field extraction**

**- Completeness checker**

**- Duplicate complaint detection**

**- AI risk classification (Critical/Major/Minor)**

**- Root cause + CAPA recommendation**

**- AI-generated complaint summary**
